# Flor de Lis — Floricultura

Site responsivo de apresentação de uma floricultura, feito com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia os arquivos para uma pasta.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Personalizações importantes
- **Nome e identidade:** procure por `Flor de Lis` e `flor de lis` em `index.html`.
- **WhatsApp:** abra `script.js` e troque `5500000000000` pelo número da loja com código do país e DDD (somente números).
- **Produtos:** edite os cards dentro da seção `#products` em `index.html`. Atualize nome, descrição, preço, categoria e imagem.
- **Fotos:** substitua os endereços das imagens do Unsplash pelas fotos da floricultura.
- **Cores:** altere as variáveis visuais diretamente no início de `style.css` (cores principais: `#354d3b`, `#a86d68` e `#fbfaf6`).

## Recursos
- Layout adaptável para celular, tablet e computador.
- Menu mobile.
- Filtro de categorias de buquês.
- Botões de adicionar à sacola com contador e total demonstrativo.
- Atalho para atendimento via WhatsApp.

> Observação: a sacola é demonstrativa e não processa pagamentos nem registra pedidos. Para vender online de verdade, será necessário integrar checkout ou backend.
